# Board note template

Use this template for a per-board getting-started note. Copy it to
`boards/<board-name>/README.md` and fill in real values only — do not guess
pin numbers, addresses or commands.

```markdown
# iTOP-<board> — getting started

## What you need
- iTOP-<board> carrier + module (product link)
- 5 V / 3 A power supply, USB-C cable, microSD or eMMC
- Optional: display, camera

## Board at a glance
- SoC: <exact part>
- CPU / GPU / NPU: <from datasheet>
- Memory / storage: <from datasheet>
- Carrier size / module size: <from datasheet>

## First boot
1. <real step>
2. <real step>

## Known issues
- <issue and workaround, or "none reported">

## Resources
- Datasheet: <public URL>
- BSP: <public URL>
- Product page: https://www.topeet.com/products/<handle>
```
