# TOPEET Embedded — Documentation & Resource Index

TOPEET (Beijing TOPEET Electronics Co., Ltd.) designs and manufactures industrial
single-board computers (SBCs), system-on-modules (SoMs) and development kits for
edge computing, machine vision, digital signage, NVR and industrial IoT.

All product pages, current pricing and ordering are on the official store:

**https://www.topeet.com**

---

## What this repository is for

This repository is the public, permanent home for TOPEET technical documentation
and resource links. It exists so that engineers can find datasheets, BSP
information and getting-started material without depending on a web form or a
support ticket. Product pages on topeet.com link here for downloads.

_Note: this is a documentation index. Binary BSP images and large datasheet files
are linked from the project table below rather than committed to git._

---

## Getting started

1. Pick a board from the platform table above.
2. Open its product page on https://www.topeet.com for ordering options
   (standard / 4G / 5G kits, connector or stamp-hole SoM).
3. Use the resource links for that platform below for datasheet and BSP.
4. For board-specific questions, open an issue in this repository or use the
   contact page: https://www.topeet.com/pages/contact

Two-piece sample pricing (15% off) is shown directly on each product page.
For custom carrier boards, volume pricing and BSP adaptation, contact us through
the form above.
